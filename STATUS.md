# Status legend

Allowed `status` values for every project’s `project.json`.

**Edit only this file** when adding or removing a status. The dashboard publisher copies this file into `what-am-building` on each run so the two stay aligned.

| Status | Meaning |
|--------|---------|
| `idea` | Early concept; little or no code yet |
| `exploring` | Researching or validating an approach |
| `building` | Active development |
| `testing` | Being tested or validated |
| `launching` | Preparing for release or first real use |
| `active` | Running / actively maintained |
| `paused` | Temporarily inactive |
| `shipped` | Finished or released for its intended use |
| `archived` | No longer pursued |
