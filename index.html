How this page is made

Every day a GitHub Actions job scans my repositories. Each one carries a small project.json file with a status, tags and languages, plus its GitHub description. The job turns the ones I have marked as shareable into a catalog and publishes this static page. Nothing here is written by hand, so the dates and counts are real, and a project only appears if I chose to list it.

Some entries are private repositories. For those you see only the name and a short summary, never the code. Some of the work is in networking and automation: knowing how automated traffic behaves helps me build services that handle it well. If you would like to see how one of the private projects works, ask for a walkthrough.

      WireGuard for IoT: encryption-optional research

      Lab research on WireGuard for constrained IoT and SBC devices that lack hardware crypto acceleration. Measures CPU and throughput when both peers optionally skip transport encryption on hops you own. PC results: about 42% lower per-packet time; fast VM tunnels show little gain. Phone and board field work still open. Lab only—not a production VPN.
